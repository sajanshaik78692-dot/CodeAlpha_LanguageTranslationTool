\## 📌 Overview

A Python desktop application built with Tkinter that translates text across multiple languages in real time and provides integrated text-to-speech audio playback and clipboard copying.



\## ✨ Features

\- \*\*Multi-Language Support:\*\* Translate between English, Hindi, Telugu, Spanish, French, German, and Japanese.

\- \*\*Instant Language Swap (`⇄`):\*\* Quickly reverse source and target languages with one click.

\- \*\*Text-to-Speech (TTS):\*\* Listen to spoken pronunciations of translated text.

\- \*\*Clipboard Integration:\*\* Copy translated results immediately via `pyperclip`.



\## 🛠️ Tech Stack

\- \*\*Language:\*\* Python 3

\- \*\*Translation Engine:\*\* `deep-translator` (Google Translator API)

\- \*\*Speech Synthesis:\*\* `gTTS` / `pyttsx3`

\- \*\*GUI \& Utilities:\*\* `tkinter`, `pyperclip`
